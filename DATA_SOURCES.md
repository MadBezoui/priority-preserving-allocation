# Data attribution and interpretation

1. Artur Trindade (2015), **ElectricityLoadDiagrams20112014**, UCI Machine Learning Repository, DOI [10.24432/C58C86](https://doi.org/10.24432/C58C86), CC BY 4.0. Original archive: https://archive.ics.uci.edu/static/public/321/electricityloaddiagrams20112014.zip . Measurements are kW at 15-minute intervals. Documented daylight-saving and pre-activation zeros are retained. Select the first 32 source columns with positive mean in 2012; divide each by its own 2012 mean; test on 2013. The resulting unweighted sum is an abstract normalized-service resource, not total kW.
2. Hadi Fanaee-T (2013), **Bike Sharing**, UCI Machine Learning Repository, DOI [10.24432/C5W894](https://doi.org/10.24432/C5W894), CC BY 4.0. Original archive: https://archive.ics.uci.edu/static/public/275/bike+sharing+dataset.zip . Use observed registered and casual hourly completed rentals, normalize by the 2011 mean total, and test on 2012. These observations are not uncensored demand. Missing-hour gaps are retained; delays count observations.

Original archives remain local. The code archive contains download and preprocessing scripts rather than redistributing either archive. Cite the creators and identify the normalization if sharing derived data after authorization. Synthetic capacities, interruptions and priority labels are experiment design choices, not dataset annotations.
